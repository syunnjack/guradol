## 2度目のときに見落としたこと

楽天と Yahoo! を外した根拠は DMMウェブサービス利用規約 第9条1項(5)
「ウェブサービスを使用して取得した商品またはサービスについての情報を、
**本プログラム以外のアフィリエイトプログラムで利用すること**」だった。
それなのに Amazon と駿河屋のリンクは残した。「画像を持たないテキストリンクだから」
と考えたのが誤りで、**この条項が禁じているのは画像ではなく情報の利用。**
検索語に使っている出演者名は DMM の API で取ったものなので、同じく当たる。
