# guradol（guradol.jp）

**グラドル名鑑。** グラビアアイドル・モデルのプロフィールと出演作品を、
名前から引くためのサイト。

- 本番URL: https://guradol.jp
- 配信: GitHub Pages（`public/CNAME` に `guradol.jp`）

## darekore.jp とは分けてある

darekore.jp はアダルト（18禁）の名鑑。**こちらは一般側だけを扱う。**
アダルトの作品・サイトへのリンクは置かない。理由は2つ。

- グラビアアイドルは事務所に所属する実在の人。18禁サイトに並べると
  削除依頼を受けやすい
- 一般サイトにしておくと広告の選択肢が増える

## 掲載データの方針

darekore.jp と同じ。

- **権利者が API で公開している項目だけを載せる。** 推測・補完・独自の評価は載せない
- 実在の人物なので、裏付けのない身体的特徴・所属・経歴を書かない
- ページには必ず出典を明示する
- 削除依頼の窓口を画面に出す

## データ取得

| 出典 | スクリプト | 中身 |
|---|---|---|
| DMM.com アフィリエイト Web サービス（一般） | `scripts/fetch-gravure.py` | 写真集 39,628件 / DVD（グラビア）11,483件 |

**アダルト（FANZA）のフロアは見ない。**

`ebook/photo` と `mono/dvd` を発売月で区切ってなめる。offset に上限があるため。
出演者は `iteminfo.actor`、分類は `iteminfo.genre`（グラビア / アイドル / セクシー）。

### 認証情報

GitHub Secrets に入れる。**リポジトリには置かない。**

| 環境変数 | 用途 |
|---|---|
| `FANZA_API_ID` | DMM アフィリエイト API ID（一般側も同じキー） |
| `FANZA_AFFILIATE_ID` | アフィリエイトID |
